# Project Ideas – from easiest to hardest

Build them one at a time. Put each one in its own folder under `projects/`, and give
each one a README that explains what it does and how to run it.

## 🟢 Level 1 – Beginner (Python, runs in the terminal)
| Project | What you'll learn |
|---------|-------------------|
| Number guessing game *(done, see `projects/01-number-guessing-game`)* | input, loops, `if`/`else`, random numbers |
| Simple calculator | functions, handling errors |
| To-do list (saved to a text file) | lists, reading and writing files |
| Rock-Paper-Scissors | game logic, keeping score |
| Password generator | strings, the `random` module |

## 🟡 Level 2 – Web basics (HTML + CSS + JavaScript)
| Project | What you'll learn |
|---------|-------------------|
| Personal portfolio website | HTML structure, CSS styling, **GitHub Pages** hosting |
| Tip / BMI calculator page | JavaScript events, the DOM |
| To-do app that remembers tasks | `localStorage`, arrays |
| Quiz app | showing questions, tracking a score |
| Digital clock / stopwatch | timers (`setInterval`) |

## 🟠 Level 3 – Intermediate
| Project | What you'll learn |
|---------|-------------------|
| Weather app | fetching data from a public API (for example, Open-Meteo) |
| Expense tracker | forms, totals, charts |
| Movie search | APIs, search, showing lists of results |
| Notes app with Flask (Python) | a backend, routes, a small database (SQLite) |

## 🔴 Level 4 – Bigger projects
| Project | What you'll learn |
|---------|-------------------|
| Blog with login | user accounts, databases |
| Chat app | real-time updates (WebSockets) |
| Automated tests + GitHub Actions | running tests on every push (CI) |

## ✅ A good GitHub habit for every project
1. Open an **Issue** that describes the project.
2. Work on a **branch** and commit small steps with clear messages.
3. Open a **Pull Request** and merge it.
4. Update the project table in the main `README.md`.
