# Number Guessing Game 🎲

The computer picks a random number from 1 to 100. You guess, and it tells you
"too high" or "too low" until you find it.

## How to run
You need Python 3 installed.
```bash
cd projects/01-number-guessing-game
python3 guess.py
```

## What this project teaches
- `input()` to read what the user types
- `while` loops and `if / elif / else`
- the `random` module
- functions (`def play()`)
